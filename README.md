# Squiz the quiz App(alpha version)
Explaination: S’Quiz the quiz app is a study-assistant mobile application designed for university students.
The name comes from a blend of “Study + Quiz” and the idea of “squeezing knowledge out of PDFs” — reflecting its mission to turn passive reading into active learning.
This app transforms PDF-based course materials into interactive quizzes, helping learners practice active recall while also benefiting from AI tutoring.

Features: 
  ■ AI-integrated PDF reader with annotation support
  ■ AI tutor (WIP: GPT → migrating to local AI model...) for asking contextual questions
  ■ Quiz generator that creates quizzes directly from PDF content
  ■ Quiz-sharing community where users can create, solve, and exchange quizzes
  ■ Download & save quizzes for offline practice

Tech Stack:
  ■ Frontend: Flutter (GetX, Syncfusion, Sqflite)
  ■ Backend: Spring Boot (WIP: spring boot → migrating to Firebase for easier management as a solo developer...)
  ■ AI : GPT API (WIP: GPT API → migrating to local AI model for larger token capacity and deeper fine-tuned quiz generation..)
  ■ Cloud: AWS → Firebase
